# Phân tích JSON

<EmbedFlowNode type="action_json_parse" />

Khối `Parse JSON` chuyển một chuỗi JSON thành một đối tượng để truy cập các trường bên trong, ví dụ phần thân của một phản hồi HTTP.

### Cài đặt

> `JSON / Giá trị` Chuỗi JSON cần phân tích.

### Đầu ra
Một đối tượng hoặc mảng. Truy cập các trường bằng `{{...}}`.
