# Nối danh sách

<EmbedFlowNode type="action_list_join" />

Khối `Join list` nối các phần tử của một danh sách thành một chuỗi, ngăn cách bởi một ký tự nối.

### Cài đặt

> `Danh sách` Danh sách đầu vào.
>
> `Ký tự nối` Chuỗi ngăn cách (mặc định `, `; dùng `\n`, `\t`).
